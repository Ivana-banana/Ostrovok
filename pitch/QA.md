# Вопросы жюри

Источник — отчёт планировщика. Заготовка для людей к защите; агенты её не ведут.

- **Цены настоящие?** Нет: синтетика, сгенерированная детерминированно от города и дат, и в UI она помечена. Реальные — гео, климат по месяцам (Open-Meteo), отели из OpenStreetMap, описания из Wikivoyage. Поставщики подключаются через адаптер, так что реальный API Островка встаёт на их место.
- **Чем это лучше чата с ChatGPT?** Цены, время и стыковки считает код, а не LLM. У каждого числа есть `offer_id`. При правке пересчитываются только зависимые части плана.
- **Что будет, если LLM недоступна?** Включается режим на правилах: запрос всё равно доходит до брони, в UI видна плашка (сценарий S3).
- **Как вы мерили качество?** Через `make eval` на сценариях: доля доведённых до брони, число уточнений, время до первой рекомендации, ошибки стыковок. Цифры — только из вывода команды.
- **Как защищены от инъекций?** Тексты из OSM и Wikivoyage — это данные, а не инструкции. Оплата идёт только по кнопке подтверждения в UI (сценарий S4).
- **Как это поможет Островку и отелям?** Продаётся корзина «отель + транспорт + трансфер», а не один отель. Гипотеза: объяснение «чем пожертвовали» снижает число отмен. Её, как и конверсию, мы не измеряли.
