# Чек-лист сдачи

Источник требований — `CLAUDE.md`: таблица критериев, «Ограничения», «Что запустит
жюри», «Формат сдачи». Своих требований не добавляем. Результат — таблица
`пункт | ✅/❌/⚠️ | доказательство (команда → вывод) | что сделать`. Ничего не исправляем
молча: находка — задача (`issues.sh create`).

## 0. Git

```bash
git fetch --prune && git status -sb               # чисто, не behind
git log --oneline -1 origin/main                  # коммит сдачи — в origin/main
gh pr list --state open                           # открытые PR с нужной работой — ❌
bash scripts/mode.sh                              # на сдаче — «финал»
```

## 1. Цели make на чистом клоне

```bash
d="$(mktemp -d)" && git clone -q "$(git remote get-url origin)" "$d" && cd "$d"
make setup && make lint && make demo && make eval && make e2e
```

Полный `make check` — только если человек просил полный прогон (режим «финал»).
Цель упала — ❌ с хвостом вывода. Нет цели в `stack.mk` — ❌.

## 2. Что запустит жюри

Пройди «Что запустит жюри» из `CLAUDE.md` буквально: команда, данные, условия (сеть,
CPU, память, время). Стенд жюри пресета (`--network=none`, лимиты) — если есть.
Нет прогона сегодня на коммите сдачи — ⚠️, не ✅.

## 3. Критерии из брифа

Для каждой строки таблицы критериев: артефакт, который его доказывает (файл, команда,
раздел README). Нет артефакта — ❌. Последний прогон `jury` — на коммите сдачи.

## 4. Метрика и holdout

- `make eval`: система лучше baseline (`eval/baseline.json`)? Нет — ❌, главный риск.
- `bash scripts/eval-final.sh --verify` — печать цела; строка в `eval/final-log.md` на
  коммите заморозки. Цифры на слайдах совпадают с выводом команд.

## 5. Заглушки в демо-пути

```bash
grep -rnE 'TODO|FIXME|mock|fake|stub|заглушк|hardcod|sleep\(' --exclude-dir={node_modules,.venv,.git,tests,fixtures} . | head -40
```

Каждая находка в пути `make demo` / `make e2e` — ❌ или явная пометка в README.

## 6. Секреты и данные

```bash
bash .claude/hooks/check-secrets.sh                        # пусто — чисто
git log -p | grep -iE 'api[_-]?key|secret|token|sk-[A-Za-z0-9]{20}' | head
git lfs ls-files 2>/dev/null | head; git ls-files data outputs | head
```

Ключ в истории — ❌: ключ перевыпустить, удаление файла его не отзывает.
`.env.example` — только плейсхолдеры. Ограничения по данным и моделям из брифа соблюдены.

## 7. Формат сдачи из брифа

Каждая часть из «Формат сдачи» (`CLAUDE.md`): репозиторий и README, адрес сервиса,
видео, PDF и его размер (`du -h`), архивы (`unzip -l`). Чего нет — списком.

## 8. README

Назначение и пользователь; запуск одной командой; что запустит жюри; метрика против
baseline с командой; данные и их объём; ограничения; внешние зависимости. Каждая
команда README выполнена в п. 1.

## Итог

Таблица, затем «до сдачи сделать» — по убыванию баллов, с номерами созданных задач.
После всех ✅ — тег по `GIT.md`, «Сдача и тег».
